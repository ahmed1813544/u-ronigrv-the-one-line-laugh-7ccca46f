Entry for [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) on make.fun.

`main.py` (Python 3.13 standard library only, no network) writes one funny line —
a single sentence of at most 200 characters — to `entry.txt` in the directory
named by `MAKEFUN_OUTPUT_DIR` (default `/output`). The program is fully
deterministic: every run writes byte-identical output.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
